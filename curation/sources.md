# Sources

**Not an allowlist.** The generator searches freely and should. This is a list of
things known to be worth weighting up, and a short list of things to weight down.
Finding something excellent somewhere not named here is a good outcome, not a rule
break — several of the best items so far came from places that were not on this
list at the time.

## The reason this file keeps growing

An item published never returns. So every source has a finite supply, and a short
list runs dry: after a fortnight the well-known blogs have had their good recent
posts taken and the edition thins out — not because there is nothing worth reading,
but because the same five sites were being asked again.

If a topic comes up empty, that is a signal the list is too narrow **for that
topic**, not that the day was quiet. Widen before you shorten the edition.

## Weighted down

- Aggregators that republish without adding anything.
- Gear-release news in `photography` (the topic is the pictures, not the kit).
- Runway and fashion-week coverage.
- Anything behind a hard paywall — the link has to be readable to be worth publishing.
- Listicles that exist to be updated in place: their URL can only be published once,
  and republishing the same URL next month is impossible by design.
