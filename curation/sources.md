# Sources

Not an allowlist — the generator searches freely. This is a list of things known to be
worth weighting up, and a short list of things to weight down.

## Trusted

| Source | Topic | Notes |
|---|---|---|
| EMCrit | medicine | Highest weight for timely |
| LITFL | medicine | ECG and teaching cases |
| First10EM | medicine | Evidence appraisal |
| Owen Cuts | records | Creator; the model for record writing |
| Aquarium Drunkard | records | Deep listening |
| 35mmc | photography | Film technique, user reports |
| Casual Photophile | photography | Film cameras |
| Heddels | fashion | Construction and provenance |
| Mutimer | fashion | Direct — restocks are timely |
| Asha Jasper | fashion | Direct |
| Broadsheet Melbourne | melbourne | Dining openings |
| Time Out Melbourne | melbourne | What's on |
| Eurogamer / IGN | gaming | Release news |
| Studio devblogs | gaming | Enshrouded, Dragonwilds — first-party patch notes |

## Weighted down

- Aggregators that republish without adding anything.
- Gear-release news in `photography` (the topic is the pictures, not the kit).
- Runway and fashion-week coverage.
- Anything behind a hard paywall — the link has to be readable to be worth publishing.
